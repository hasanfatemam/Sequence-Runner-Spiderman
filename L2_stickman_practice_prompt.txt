Create a complete **Python endless runner game** using **Pygame**.

## Game Concept

Build a 2D side-scrolling endless runner game.

The player controls a character/sprite that appears to run continuously. The character should remain approximately in the same horizontal position on the screen while the **environment, ground, and obstacles move from right to left**, creating the illusion that the character is endlessly running forward.

The game should continue indefinitely until the player collides with an obstacle.

## Player

* Add a player character sprite.
* The player should continuously appear to be running.
* Keep the player near the left side/center-left of the screen.
* The player should automatically remain on the ground when not jumping.
* The player should **jump when the SPACE key is pressed**.
* The player should not be able to perform unlimited jumps in the air.
* Allow only one jump at a time.
* Once the player lands, SPACE can be pressed again to jump.
* Make the jump smooth and natural using velocity/gravity rather than instantly moving the player up and down.

## Endless Scrolling

The game should give the feeling that the player is continuously running.

Instead of moving the player across the screen:

* Move the ground/environment from right to left.
* Move obstacles from right to left.
* Spawn new obstacles from the right side of the screen.
* Remove obstacles after they leave the left side of the screen.
* Continuously generate new obstacles so the game can theoretically continue forever.

The scrolling speed should gradually increase as the player's score increases, making the game progressively harder.

## Obstacles

Create multiple types of obstacles.

Examples:

1. **Cactus**

   * Different cactus shapes/sizes.
   * The player must jump over them.

2. **Fireball**

   * A fireball moving along the ground.
   * The player must jump over it.

3. **Rock**

   * A rock obstacle that the player must avoid.

4. **Tall obstacle**

   * A taller obstacle that requires a properly timed jump.

The obstacle system should be designed so that adding additional obstacle types later is easy.

Randomly select obstacles while ensuring that they are reasonably spaced and that the game remains playable.

## Collision

Implement collision detection between the player and obstacles.

If the player touches an obstacle:

* Stop the game.
* Display a **GAME OVER** screen.
* Display the player's final score.
* Provide an option to restart the game.

Use appropriate collision rectangles/hitboxes rather than relying only on exact image boundaries.

## Scoring

Create a score system.

* Start the score at 0.
* Every time the player successfully passes an obstacle, increase the score by **1**.
* Display the score prominently in the top-right corner.
* The score should update smoothly during gameplay.
* When the player passes an obstacle, make sure it is counted only once.
* Optionally display a high score.

The score should also influence difficulty by gradually increasing the scrolling speed.

## Game States

Implement clear game states:

1. **Start Screen**

## Difficulty

The game should progressively become more challenging.

For example:

* Start with a relatively slow movement speed.
* Gradually increase the speed as the score increases.
* Reduce the average time available to react.
* Continue spawning obstacles indefinitely.

However, **do not make the game unfair**. The player should always have a reasonable opportunity to jump over an obstacle.

Avoid generating impossible obstacle combinations.

## Important Gameplay Requirement

The most important visual effect is that **the player appears to be running continuously while the world moves toward the player**.

The player should NOT simply run from the left side of the screen to the right.

The intended gameplay should feel similar to an endless runner:

**Player stays mostly in one place → obstacles come toward player → press SPACE to jump → successfully cross obstacle → gain 1 point → game continues → speed gradually increases.**
